Create your bot

Make a bot and paste its token▼
A "bot" here is just an account you own that this tool logs in as. Making one takes about two minutes and costs nothing. You will not write any bot code. It exists so something has permission to create your channels.
Step by step, assuming you have never done this
  1. Open discord.com/developers/applications in a new tab.
    Log in with the same Discord account you use normally. It is the ordinary Discord login, not a separate developer account.
  2. Top right of that page, click New Application.
  3. Type a name, for example Steward. Tick the box agreeing to the Developer Terms of Service, then click Create.
    This name is internal. It is not your server's name and you can change it later.
  4. You land on a page called General Information. In the menu down the left side, click Bot.
    Everything from here on is on this one page, working straight down it. You should not need to scroll back up.
  5. Token is the first section. Click Reset Token, confirm with Yes, do it!, and enter your two-factor code if your account has one.
  6. A long line of random characters appears with a Copy button. Click it, then paste it straight into the box at the bottom of this page so you cannot lose it. Then come back here and finish the last three steps.
    Discord shows a token once and never again. If you lose it, press Reset Token for a new one, which invalidates the old.
  7. Next section down, Authorization Flow. Turn OFF the switch labelled Public Bot.
    This stops anyone else adding your bot to their server. Leave it on and strangers can invite it.
  8. Next section down, Privileged Gateway Intents. Turn ON the switch labelled Server Members Intent. Leave Presence Intent and Message Content Intent OFF.
    Server Members lets the ledger see who joins and leaves. Message Content stays off deliberately: the ledger records who posted where and when, never what was written. Less to protect, and an honest answer when somebody asks what is stored.
  9. A green bar appears at the bottom. Click Save Changes.
    Skip this and the two switches above do not stick, and the ledger fails to start later with no obvious reason why.
The token is a password. Do not paste it anywhere except the box below. Not in a chat, not in a screenshot, not in a message to a friend, not into an AI assistant, not into a repo. Anyone who sees it controls the bot until you reset it. If it does get out, the fix is quick and free: Developer Portal, your app, Bot, Reset Token. The old one dies instantly.

Add the bot to your server

Authorize it into your server▼
You need to have made the server yourself first. Bots can no longer create or own Discord servers, so this tool fills in a server that already exists. An empty one is exactly right.
I have not made the server yet
  1. In the Discord app, look at the narrow column of round server icons on the far left.
  2. At the bottom of that column, click the green + button. Its tooltip says Add a Server.
  3. Click Create My Own, then For me and my friends.
  4. Give it a name and click Create. You can rename it, and set its icon, in step 4 of this page.
Adding the bot
  1. Click the button below. It opens Discord's authorize page in a new tab, with everything already filled in.
  2. In the dropdown labelled ADD TO SERVER, pick your server.
    Only servers where you can Manage Server appear here. If yours is missing, you are not its owner or an admin.
  3. Click Continue, then Authorize. Solve the captcha if it asks.
  4. Come back to this tab and click I have added it.
Why it asks for Administrator. The blueprint creates a Dev role that carries Administrator, and Discord refuses to let a bot hand out a permission it does not hold itself. It is your own server and the bot is private, so this is safe. Step 6 shows you how to reduce it afterwards if you want to.
